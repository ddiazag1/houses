How this was built

Sheet A/1 is a different job. Its title block reads “NEW HOME FOR SOMEONE, project 0200, file JEFF”, with no date. A/2, A/3 and A/4 all read “NEW ADDITION FOR KEVIN AND STEPHANIE McDOWELL, file 0604-A1, project 0604, 6/30/07”. Nothing from A/1 is used in this model.

Read off the McDowell sheets:

  • 70′-0″ × 24′-2½″ new foundation (A/4), split 37′-0″ two storeys + 33′-0″ single storey (A/2) — the same three masses A/3 draws left to right
  • Gable end 6′-6″ | 11′-0″ | 6′-6″, two 5′0×5′0 windows (A/2) — the same pair drawn in the rear elevation gable
  • Bedroom #5 16′-2″ × 12′-10⅜″, bedroom #4 15′-9¾″, closet 7′-6″, stair 3′-8″ up / 3′-9½″ down, bedroom #4 window 5′0×4′0 (A/2)
  • 20 course “LOGIX” 40″-high block stem wall o/ cont. 18″×10″ footing w/ (2) #5 rebar; 4″ slab w/ radiant in-floor heat; 2×4 ponywall @ 16″ o.c.; drill 18″ into existing footing, epoxy-grout new rebar (A/4)
  • Two storeys. The gable faces front and rear: its rake scales 17′-2″ run to an 8′ rise (≈ 6:12) and peak-to-base scales 26′-6″, which fits a 37′ gable span, not 24′ (A/3)

Missing sheet. The addition’s main-floor plan is not among the photos — they run A/2 upper, A/3 elevations, A/4 foundation. The main level is shown as open volume, with only the openings the elevations give.

Assumed: 8′-0″ walls, 12″ floor system, 6:12 roof and 18″ eaves scaled off A/3, grade 1′ below slab. Upper-level partition positions are scaled from A/2, not dimensioned.
